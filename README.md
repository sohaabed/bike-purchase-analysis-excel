# Bike Purchase Analysis Dashboard

## 📊 Project Overview

This project analyzes customer data to identify patterns and factors associated with bike purchases.

An interactive Excel dashboard was developed to explore customer demographics, income, occupation, commuting distance, and other customer characteristics in relation to bike purchasing behavior.

## 🎯 Project Objectives

- Analyze customer demographics and purchasing behavior.
- Identify patterns among customers who purchased bikes.
- Explore the relationship between income and bike purchases.
- Analyze bike purchases across different occupations and commuting distances.
- Present key findings through an interactive Excel dashboard.

## 🛠 Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Excel Dashboard

## 📈 Dashboard

The dashboard provides an interactive view of the analyzed data and allows users to explore customer characteristics and bike purchasing patterns.

Key analysis areas include:

- Customer demographics
- Income analysis
- Occupation
- Commute distance
- Bike purchase behavior
- Customer-related comparisons
